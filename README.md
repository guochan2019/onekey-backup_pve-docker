# Docker 数据一键备份/还原脚本（onekey-backup_pve-docker）

在 PVE 宿主 / Docker LXC 上一键备份、还原 Docker 数据：按目录类型分类打包（容器目录子目录分别打包 + 普通目录整体打包），zstd 多线程压缩（CPU 占用可控）。备份与还原均为**交互式选择**（编号/范围/关键字/全部），还原额外支持历史版本。

## 快速开始

```bash
# 下载脚本
wget https://raw.githubusercontent.com/guochan2019/onekey-backup_pve-docker/main/onekey-backup_pve-docker.sh
# 运行（交互菜单）
bash onekey-backup_pve-docker.sh
```

首次运行自动检测并安装缺失依赖（zstd）。

## 菜单选项

| 选项 | 说明 |
|------|------|
| **1. 备份** | 源目录（默认 `/mnt/nvme1`）下所有一级目录按类型**分组展示 → 交互选择**（可全部或选择性备份）→ 打包 `.tar.zst` 到备份目录（默认 `/mnt/backup/pve-docker`，可交互修改） |
| **2. 还原** | 扫描备份目录最新备份 → 分组展示 → 交互选择 → 解包到还原目录（默认 `/mnt/nvme1`，可交互修改） |
| **0. 退出** | — |

## 备份逻辑（目录分类）

源目录下的一级目录分两类处理（容器目录列表可在脚本顶部 `CONTAINER_DIRS` 扩展）：

| 类型 | 目录 | 打包方式 | 输出位置 |
|------|------|----------|----------|
| 容器目录 | `appdata`、`appdata_deb` | 其下**容器子目录分别打包** | `<备份目录>/<容器目录>/<容器名>_<YYYYMMDD>.tar.zst` |
| 普通目录 | `docker`、`docker_deb`、`mediaout` | **整个目录打包** | `<备份目录>/<目录名>_<YYYYMMDD>.tar.zst` |

文件名：`<目录名>_<YYYYMMDD>.tar.zst`（同日重跑覆盖）。

## 备份交互

备份前**分组展示**待备份内容（[顶层目录] / 各容器目录组，显示源大小，挂载点标注 ⚠），选择支持：

| 输入 | 含义 | 示例 |
|------|------|------|
| 编号 | 备份单个 | `8` |
| 空格分隔编号 | 多选 | `1 4 8` |
| 范围 | 区间 | `1-5` |
| 关键字 | 模糊匹配目录名 | `joplin` 命中 joplin |
| `a` | 全部 | `a` |

可多轮追加选择（回车完成）。仅打包选中项；未选择时报错退出。

## 还原交互

还原列表**分组展示**（顶层目录 / 各容器目录组），选择支持：

| 输入 | 含义 | 示例 |
|------|------|------|
| 编号 | 还原单个 | `8` |
| 空格分隔编号 | 多选 | `1 4 8` |
| 范围 | 区间 | `1-5` |
| 关键字 | 模糊匹配目录名 | `joplin` 命中 joplin |
| `v<编号>` | 查看该条目**全部历史版本**并选择 | `v8` → 版本列表 → 选版本号 |
| `a` | 全部最新 | `a` |

可多轮追加选择（回车完成）。解包自动路由：顶层包 → `还原目录/`，容器包 → `还原目录/<容器目录>/`。解包前显示每个包的实际目标 + 覆盖确认（默认 n）。

## 环境要求

- **PVE 宿主 / Debian Docker LXC**（能访问源目录与备份目录的机器）
- root 权限
- 依赖 `zstd`（缺失自动 `apt install`）
- 还原兼容旧格式 `.tar.bz2` 包（GNU tar 自动识别）

## 性能与资源控制

| 项 | 说明 |
|---|---|
| 压缩 | `zstd -T$(nproc) -6` 多线程（级别 6 平衡） |
| 线程数可调 | 默认全核；临时限核：`ZSTD_THREADS=4 bash onekey-backup_pve-docker.sh`，或改脚本顶部默认值 |
| CPU 优先级 | `nice -n 19` + `ionice -c3` 降优先级——同机其他服务忙时备份自动让位，不抢资源 |
| 进度显示 | 每个包实时显示已打包/已解压大小 + 耗时；**每 10 秒强制刷新**（大目录长时间无变化也能看到进度） |

## 容错处理

- **tar 退出码分级**：`0`=成功；`1`=警告（运行中文件变化，容忍并提示，不中断）；`≥2`=错误（报错停止）
- **socket 文件**：tar 无法归档，显示为 info 提示（正常，socket 无需备份），不当作风险警告
- **运行中数据库**（如 postgres WAL）：打包期间文件变化会提示"该包可能不一致，建议停服后重备"——对 joplin/Immich 等含数据库的容器，如需可靠备份建议先停容器

## 验证

```bash
# 备份产物
ls /mnt/backup/pve-docker/                          # 顶层包 + 容器目录子包
file /mnt/backup/pve-docker/docker_20260816.tar.zst # Zstandard compressed data

# 还原验证（还原到测试目录后与源对比）
du -sh /mnt/nvme1/appdata_deb/<容器> /mnt/nvme1/test/appdata_deb/<容器>
diff <(cd 源目录 && find . -type f | sort) <(cd 还原目录 && find . -type f | sort)
```

## 注意事项

1. **备份目录勿设源目录内部**：脚本会警告（同一挂载下备份文件占用源盘空间）。
2. **运行中数据库的一致性**：目录级备份不保证数据库崩溃一致性（postgres 需 WAL 归档或停服），tar 会检测文件变化并提示。
3. **旧 `.tar.bz2` 包**：还原扫描同时识别 `.tar.zst` 与 `.tar.bz2`，旧包可直接还原（新备份一律 `.tar.zst`）。
4. **同日重跑**：覆盖同名备份文件，不保留同日多版本；跨日版本在还原 `v<编号>` 中可选。
5. **还原是覆盖操作**：解包目标已有文件会被覆盖，执行前有确认环节（默认 n）。
